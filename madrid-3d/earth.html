🔑 Tu clave de Google Maps

Para mostrar los mapas 3D fotorrealistas, esta página se conecta a Google desde tu propio dispositivo. Necesitas una API key de Google Maps Platform con el Map Tiles API activado.

Se guarda solo en este móvil (localStorage). No se envía a ningún otro sitio ni se sube al repositorio.

¿Cómo obtenerla? Consola de Google Cloud → APIs de Maps → habilita Map Tiles API → Credenciales → Crear clave de API.
